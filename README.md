# Mio Agente AI / Linea AI

La documentazione principale e permanente è [outputs/mio-agente-ai/README.md](outputs/mio-agente-ai/README.md).

Per usare il sito sul Mac apri **Apri il sito.command** e lascia aperto il Terminale. Il sito resta privato: http://127.0.0.1:8765/.

La cartella operativa è **Documenti → GitHub → linea-ai**. La precedente cartella sul Desktop non deve più essere modificata. GitHub Desktop deve mostrare il repository `linea-ai`; i commit locali non aggiornano da soli un host. Per mantenere privata questa fase, usare un ramo di sviluppo senza deployment e non effettuare merge nel ramo collegato all’host. Per trasferire il progetto leggi [TRASFERIRE-SU-UN-ALTRO-PC.md](TRASFERIRE-SU-UN-ALTRO-PC.md).

Email di prova: `python3 linea.py emails` genera una pagina riservata al gestore, indicando dove aprirla. Pagamenti fittizi: **Spazio aziendale → Portafoglio → Laboratorio pagamenti**. Nessun denaro reale.
